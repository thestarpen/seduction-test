# seduction-test
매력 유형분석 테스트
01. The Seductive Character — 매력의 유형
Siren, Rake, Ideal Lover, Dandy, Natural, Coquette, Charmer, Charismatic, Star
내가 사람을 끌어당기는 주된 방식은 무엇인지 진단해. 9가지 유형의 점수를 각각 계산해 복합적인 성향도 보여줄 거야.












02. The Anti-Seducer — 매력을 방해하는 습관
자기 몰입, 과도한 표현, 상대에 대한 관심 부족, 눈치 부족 등
매력이 부족한 사람이라고 낙인찍는 대신, 관계에서 반복되는 행동 중 무엇을 개선해야 하는지 찾아내.












03. The Seducer's Victims — 내가 반응하는 매력
책에 등장하는 18가지 유형의 관점
내가 어떤 사람에게 끌리고, 어떤 관심과 분위기에 마음을 여는지 분석해. 나의 매력 유형과 상대에게 원하는 매력 유형을 구분하는 데 사용해.
